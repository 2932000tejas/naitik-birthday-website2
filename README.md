# NAITIK-006 — A Mission to Remember

A responsive, static React + Vite birthday adventure. The app uses JavaScript and CSS-only scene art/animations to keep the bundle and setup small. Real photos and audio remain replaceable local assets in `public/assets/`.

## Run locally

```sh
npm install
npm run dev
```

Build with `npm run build`; preview the static output with `npm run preview`. Vite uses relative asset paths, so the generated `dist/` folder can be published at a GitHub Pages project subpath. Configure GitHub Pages to serve `dist/` through your chosen deployment workflow.

## Add the birthday media

See [`public/assets/README.md`](public/assets/README.md) for filenames and notes. The site does not upload personal media. Avoid adding private photos or recordings to a public repository unless you want them publicly accessible.

## Journey

Mission Control → automatic Lift Off → three sequential worlds and signal fragments → rocket assembly and signal sequence → Birthday Planet, photos, exact Marathi message, voice note, then song. Missing media has graceful placeholders and controls. Reduced-motion preferences are respected.
