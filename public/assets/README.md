# Birthday media

Replace these paths with the owner's permitted media files. Keep the filenames below so the app can find them:

- `naitik-photo-1.jpg` — first real photo
- `naitik-photo-2.jpg` — optional second real photo
- `voice-note.m4a` — personal voice recording (M4A/AAC is supported by current Chrome, Safari, and Edge; use MP3 if targeting a browser/device that cannot decode the recording)
- `birthday-song.mp3` — Hindi birthday song you have permission to use

The app shows a graceful photo placeholder while an image is absent. Missing audio is handled in the finale with retry and skip-to-song controls. Media stays local in this folder and is served as part of the static site. For a private celebration, remember that anything deployed to a public GitHub Pages repository is publicly accessible.
